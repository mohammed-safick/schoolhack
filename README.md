# School Hack · live demo

**Open it: <https://mohammed-safick.github.io/schoolhack/>**

Grade 9 chemistry practice for the Berlin curriculum, in German and English.
Sign in with `admin` / `admin` as a student or a teacher. Click **How it works**
to see the app explained by the Archify agents.

This repository only hosts the standalone website (`index.html`, one file, no
server) on GitHub Pages. The source code, the full app and the team live in
[RezaurRahman47/SchoolHack](https://github.com/RezaurRahman47/SchoolHack)
(`website/index.html`).

**Update the live site:** copy the newest `website/index.html` from the main
repository over `index.html` here and push. GitHub Pages publishes it within a
minute or two.
