# School Hack · live demo

**Open it: <https://mohammed-safick.github.io/schoolhack/>** (forwards to the full app at <https://schoolhack.onrender.com>)

The earlier standalone website is still here: <https://mohammed-safick.github.io/schoolhack/classic.html>

Grade 9 chemistry practice for the Berlin curriculum, in German and English.
Sign in with `admin` / `admin` as a student or a teacher. Click **How it works**
to see the app explained by the Archify agents.

`index.html` forwards to the full app on Render (branch `safick_v1` of the team repository).
`classic.html` is the standalone website (one file, no server). The source code, the full app and the team live in
[RezaurRahman47/SchoolHack](https://github.com/RezaurRahman47/SchoolHack)
(`website/index.html`).

**Update the classic site:** copy the newest `website/index.html` from the main
repository over `classic.html` here and push. GitHub Pages publishes it within a
minute or two.
